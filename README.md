# Ceylon Leaf — E-Commerce Website

A responsive Ceylon tea storefront built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build tools or backend are required.

## Features

- Tea catalog with category filters, search, and price/name sorting
- Tea garden elevation selector for five Sri Lankan growing regions
- Product photography with a color fallback when an image cannot load
- Shopping bag with quantity controls and remove actions
- Cart saved in browser local storage
- Demo checkout and order history saved in browser local storage
- Product search shortcut (`/`), newsletter signup demo, and responsive layout
- Keyboard focus styles and reduced-motion support

This is a frontend learning project. Checkout does not collect payment or send customer data to a server. Product photography and fonts load from external services.
